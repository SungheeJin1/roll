# 원숭이 인형의 겨울

눈 오는 밤 영상(원숭이 인형 '롤숭이'가 이불을 옷장으로 옮기고, 곰인형과 함께 들어가 작은 등을 켜는 장면)을 이어서 만든 한국어 브라우저 게임입니다.

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다 (`assets/` 폴더가 같은 곳에 있어야 합니다).

## 그림
- **방(밤)·옷장 장면·캐릭터·곰인형·이불 더미**: 원본 영상 프레임에서 그대로 가져왔습니다. 캐릭터와 말풍선·자막·UI는 AI 인페인팅(LaMa)으로 지우고, 캐릭터는 배경 제거(ISNet)로 오려 냈습니다.
- **표정**: 영상의 다른 장면(무표정·웃음·잠)에서 눈과 입을 옮겨 와 정면 모습에 입혔습니다.
- **아침(낮) 방·아침 옷장**: 밤 장면을 색 보정해 만들었습니다.
- **바깥 산책**: 영상에 없는 장면이라 같은 부드러운 3D 느낌으로 픽셀 단위 조명을 계산해 렌더링했습니다 (낮/밤 두 벌).

## 장면
1. **눈 오는 밤 (방)** – 이불 더미를 옷장으로 밀어 넣고, 곰인형도 데려간 뒤 옷장 안으로
2. **옷장 안** – 작은 등을 켜서 몸을 녹이고 잠자기
3. **아침의 방 (낮)** – 이불 더미 꺼내기, 곰인형 창가에 앉히기, 빨간 목도리 두르기
4. **바깥 산책** – 눈사람 만들기 → 도토리 줍기 → 아기새에게 주기 → 노을 모닥불 → 밤이 되면 집으로 (다시 밤으로 이어짐)

설정(⚙)에서 각 장면으로 바로 이동할 수 있고, 밤 산책도 고를 수 있습니다.

## 조작
- 이동: `W A S D` / 방향키 / 화면 왼쪽 아래 패드 / 바닥이나 물건을 탭
- 행동: `E` / 스페이스 / 화면의 ◎ 버튼
- 설정: ⚙ 또는 `Esc`, 소리: 🔇 버튼 또는 `M`

## UI (영상과 같은 위치·크기)
- 왼쪽 위: 이름(롤숭이) + 체력바 / 가운데 위: 퀘스트 배너 / 오른쪽 위: 미니맵·소리·설정
- 오른쪽 아래: 체온 게이지 (병아리 표시가 따뜻할수록 위로) / 왼쪽 아래: W·A·S·E 패드와 ◎ 버튼
- 말풍선(초상화 포함)과 하단 자막
